2) フォームを“本当に届く”形に（Formspree想定）

ACTION_URL を実エンドポイントに差し替え。自動返信やThanks遷移は後回しでOK。まずは受信を保証。

<form action="https://formspree.io/f/xxxxabcd" method="POST" class="form">
  <label>お名前<input name="name" autocomplete="name" required></label>
  <label>メール<input type="email" name="email" autocomplete="email" required></label>
  <label>内容<textarea name="message" rows="5" required></textarea></label>

  <!-- スパム対策（ハニーポット） -->
  <input type="text" name="_gotcha" style="display:none" tabindex="-1" autocomplete="off">
  <!-- 件名（管理用） -->
  <input type="hidden" name="_subject" value="ココもやり展 お問い合わせ">

  <button type="submit" class="btn">送信</button>
</form>


受信確認できたら、/thanks.html を用意して _next（旧API）やFormspree側のRedirect設定で遷移させれば十分。

3) “3つのテーマ”は折りたたみで全5問まで見せ切る

トップは今の2問＋「他3つ」で軽く、詳細は <details> に格納して5問全部を置く（情報探索の手応えUP／滞在時間UP）。

<details>
  <summary>🎓 就活生の本音（青）— 全5問を見る</summary>
  <ol>
    <li>面接で「自分らしさ」を…本当のあなたですか？</li>
    <li>就活を始めてから「これは違う」と感じた瞬間は…？</li>
    <li>「安定」と「挑戦」、どちらかしか選べないとしたら…？</li>
    <li>「必要とされる人」と「なりたい自分」、どちらが先…？</li>
    <li>もし「就職しない」選択肢があったら…？</li>
  </ol>
</details>


※文面は企画書どおりでOK（LPでは句読点と重複表現だけ少し間引く）。

4) マップ埋め込みの“レスポンシブ最適化”

iframeは横幅に強いが縦が伸びがち。アスペクト比コンテナで固定してCLSを防ぐ。

/* 追加（style.css） */
.map { position: relative; width: 100%; aspect-ratio: 16 / 9; }
.map iframe { position:absolute; inset:0; width:100%; height:100%; border:0; }


HTMLは width/height を外してOK（loading="lazy" は現状のままで良い）。

5) 画像の軽量化＆将来の地雷回避

いま参照している .JPG / .PNG はOK。リポジトリにある .HEIC はブラウザ非対応が多いので、使うなら .jpg/.webp に変換してからリンクする。

<img> には既に loading="lazy" があるので、さらに decoding="async" を足して初期表示を軽くする。

<img src="image/回答している様子.JPG" alt="参加者が付箋に回答を書いている様子" loading="lazy" decoding="async">
